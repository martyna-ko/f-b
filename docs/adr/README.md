# Architecture Decision Records (ADRs)

Short records of important decisions: the context, the decision and its consequences.

- One decision per file, numbered: `0003-short-title.md`.
- Accepted ADRs are never rewritten. To change a decision, add a new ADR that replaces the old one.
- Status: Proposed → Accepted (by a human) → Replaced.
