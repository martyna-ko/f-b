# Find Balans Design System

A shared source of truth for **human designers and developers** and **AI agents**.

- **Foundations** — design tokens (colour, typography, spacing) — _coming in the tokens pull request._
- **Components** — each with purpose, anatomy, variants, states, accessibility and usage guidelines.
- **Rules** — see `AGENTS.md` in the repository root.

Status: scaffold only. Components are added one pull request at a time.
