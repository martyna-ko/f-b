# Design tokens

Everything on this page is read from the generated tokens (`src/tokens/tokens.json`), built from `tokens/**/*.tokens.json`. To change a value, change the token file in a pull request — never this page.

**Rule for components:** use **semantic** tokens (`--color-action-primary-bg`), never primitives (`--color-brand-violet-600`) or raw values (`#8715FC`). Stylelint enforces this.
